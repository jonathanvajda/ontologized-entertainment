Build on the engine

Make the next game ontological.

The common codebase separates canonical RDF state, deterministic game mechanics, and rendering. A new game supplies its ontology, rules, projection, and visual layer without rewriting persistence or transaction handling.

Quick start

  1. 01
    Read the contracts

    Start with the boilerplate capability and technical specifications in specs/.

  2. 02
    Specify the game

    Use GAME_IMPLEMENTATION_GUIDE.md to define turns, actions, randomness, scoring, invariants, and rendering.

  3. 03
    Extend the vocabulary

    Add one focused CCO-aligned ontology and optional SHACL shapes under docs/src/ontologies/.

  4. 04
    Register trusted rules

    Import @ontologize-entertainment/game-mechanics, then register action handlers, validators, scoring functions, and projections.

  5. 05
    Ship a static PWA

    Keep the game in docs/<game-name>/, use relative module paths, add deterministic tests, and push to publish with GitHub Pages.

game.js
import {
  RdfStore,
  RuleRegistry,
  createGameEngine
} from '../packages/game-mechanics/src/index.js';

const rules = new RuleRegistry()
  .registerAction('play', gameAction);

const game = createGameEngine({
  store: new RdfStore(initialQuads),
  rules,
  seed: 'replayable'
});
