## Survey Notes

- No active `localStorage.getItem`/`localStorage.setItem` hits were found in the scanned app JS paths outside ignored vendor/minified files during this pass.
- Deprecated site-header files remain in several repos. They are not treated as canonical candidates and should be deleted during the rewiring/dead-code phase when the site header package is formalized.
- SPV's `sviz-toast-*` CSS is intentionally not the target shape. Toast CSS should converge on the unscoped shared selector contract because toast notifications are not visualizer-canvas UI.
- Theme persistence must stay on the shared project/app settings store. The new helper requires a caller-provided setting key so this package does not invent a local data-property key.
- Toast/status DOM utilities should return structured `{ ok, value }` results for no-op or render failures; core presentation functions remain pure and throwable validation should be limited to invalid durable settings operations.
