## Survey Notes

- Existing `namespace-registry` already owns CURIE expansion/compaction and prefix maps. Ontology-utils should reuse those functions directly rather than introduce another registry-facing bridge.
- Existing `rdf-io/rdf-model.js` already owns RDF/JS term construction and normalization. Ontology-utils should not duplicate `namedNode`, `blankNode`, `literal`, `quad`, or dataset helpers.
- The highest-value first promotion set is: strict absolute IRI validation, IRI token normalization, blank node/term role predicates, ontology file classification, XSD datatype helpers, and UUID creation.
- Namespace IRI normalization may belong in `namespace-registry`, not ontology-utils. It is documented here because it was found during this survey and is ontology-adjacent.
