Use this file during the namespace-prefix registry survey pass. Do not refactor while filling it out.

## Survey Notes

- The likely shared package should be named around namespace prefixes, not one file format. A useful shape is `packages/namespace-registry` with pure registry/compaction helpers and syntax adapters.
- Do not promote mutable global prefix stores as core. TOM has broad usage, but its `iriPrefixes` object is modified by UI code and should become a consumer of the shared registry.
- Longest-prefix matching appears important. Axiolotl `bestPrefixForIri` and Visual Lynx `prefixEntries` both preserve this behavior.
- Prefix extraction should be format-specific. Turtle/SPARQL, XMLNS, JSON-LD context, and N3 parser-captured prefixes have different contracts and error models.
