- **Capability family:** Tabular parsing and serialization

## Scope

This survey covers CSV, TSV, XLS, and XLSX parsing or serialization. Browser file reads and downloads are noted only when they are embedded in tabular workflows; those boundaries belong to `browser-file-io`.

## Vendor and Package Notes

- PapaParse appears in IRI Swapper for CSV/TSV mapping imports and provides better CSV coverage than local regex splitting.
- SheetJS appears in TOM, IRI Swapper, and Table Nova for XLS/XLSX handling.
- `format-registry` should remain the source for MIME/extension classification.
- `browser-file-io` should remain the source for file text/array-buffer reads and downloads.

## Survey Notes

- Table Nova currently has the most focused parser test coverage.
- TOM and OCM currently have the strongest focused serializer tests.
- IRI mapping parsing should probably be a separate domain-specific package after the generic tabular parser/serializer contract is defined.
- Visual Lynx does not currently need tabular parsing/serialization migration beyond already shared browser download utilities.
