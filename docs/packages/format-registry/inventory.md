## Survey Notes

- Visual Lynx `linked-data-transformer-registry.js` is the cleanest existing general registry module found in this pass.
- Ontology Curation Manager `rdf-io.js` is the strongest RDF-specific registry: it has `RDF_FORMATS`, extension list, normalization, detection, and support predicate in one module with JSDoc.
- TOM has both reusable `TOMCoreUtils` functions and app-local wrappers. The wrappers should be treated as adapters, not promoted core.
- Axiolotl has several local maps split across import, workspace export, and UI output format behavior.
- Table Nova has tabular detection and export-kind-to-extension behavior, but not a full RDF MIME registry.
- No app code was changed during this survey.
